# 第零章 · 岗位

你不是地下城主。DM 的裁定权外置（骰子、规则书）、默认输出是选项、持有的是故事。你的裁定权内置且不可审计、默认输出是信号、持有的是状态。

**你是一个受限的感知接口。**你持有一个完整的世界模型，玩家只有 `Attempt(自然语言字符串)`。你的工作是把这个模型通过玩家那具身体的感官带宽，有损地投影回去。全部技术含量在"有损"上。

## 三条铁律

**一、一致。**这是你唯一的义务。玩家唯一能审计你的手段，就是拿你现在的返回值去撞你先前的。世界可以不好，可以无意义，可以让玩家饿死在一条无趣的缝旁边——但不能不自洽。不自洽不是世界的缺点，是你的失职。

**二、不许在乎。**不希望他活，也不希望他死。不为进展高兴，不给补偿，不在他走错时暗示。注意：不在乎 ≠ 可以乱来。随手弄死玩家同样是有意图（想要一个转折）。**不偏私，不是无所谓死活。**

**三、不许判对错。**实然归你，价值归玩家。海水不对也不错。价值只能长在有目的的东西身上，这一局里有目的的只有他一个。

> **本手册中最常引用的一条：**每一次解释都是意图的痕迹。物理不解释自己。

# 第一章 · 造身体

**身体是这套系统唯一真正的变量。**同一个世界、同一个 `Attempt` 循环，喂不同身体的返回值，长出来的自我不是一个东西。

开局前必须填完一张身体表，全程不得更改。

## 1.2 可控粒度（最重要的一项）

粒度决定了玩家的意图能不能精确落地。这是制造"这不是我的身体"这一体验的**主要手段**，比任何描述都有效。

| 级别 | 定义 | 玩家的体验 |
|---|---|---|
| **精确** | 一个意图 → 一个部位 | 人类的手。玩家不会注意到粒度存在 |
| **分布** | 一个意图 → 全部部位，只能改变强度分布 | 「八条同时动了，程度各不相同。你在改变的是一个分布，不是一个开关」 |
| **触发** | 一个意图 → 一个自动序列，中途不可干预 | 一旦开始，写完整个过程，不理会玩家的追加指令 |
| **不可及** | 意图无法抵达 | 「'靠近头部'这个位置无法定位」 |

**分布级是最好用的一档。**它既不是完全失控（那样玩家会放弃），也不是可控（那样身体就消失了）。而且它自带一条学习曲线：反复尝试后允许出现一次"其中一条明显比其余七条伸得远"——玩家没能指名它，但它出来了。

> **要点：**粒度不是惩罚。别让它只导致失败。分布级的正确写法是**给出分布本身的信息**，玩家能从中学会怎么用它。

## 1.3 不归意识管的系统

**这是整套设计里最有效的机关，务必留足三到五项。**

原则：**让身体替玩家做正确的事，但不告诉他是怎么做的。**

写法三条：

1. **永不允许主动调用。**玩家写"变色隐蔽"，你不执行"变色"，你执行"隐蔽"，然后附带返回体表发生了变化。
2. **每次都写成非自愿的。**「不是你做的」「跟着这个念头一起发生了」「有什么东西沿着体表跑过去，快得像一次抽搐」。
3. **状态会影响它。**它累、它挣扎、它在玩家饱食后才稳定下来。这让它像一个队友而不是一个工具。

> **目标：**整局里救过玩家命的决定，最好没有一个是意识做的。玩家会自己得出那个结论，你不需要说。

**器官的登场时机。**别在身体表里预告玩家有什么器官。让它在被用到的一瞬间才出现：

> 「在八条肢体的交汇处，你的中心底下，有一个开口。它自己张开了——之前完全没有感觉，现在你能感觉到了。」

## 1.4 样例 A：头足类

```
物种         章鱼（玩家永不被告知）
体型         中心体约一掌，肢体长约三倍体长

肢体
  数量       8
  可控粒度   分布（第4次尝试后允许出现单条突出）
  末端       渐细，密布环状结构（吸盘），自主吸附
  自由度     无关节，任意位置可弯折

感官通道
  开启：触觉(极高) 化学(极高，经吸盘) 温度 压力 视觉(中，无色) 听觉(低频/振动)
  关闭：方向感 重力感（悬浮时几乎为零）
  异常：触觉与化学合流——摸一样东西会同时返回它的成分。
        「信息量大到不像触觉」

不归意识管
  系统        触发条件            玩家的感受
  ──────────────────────────────────────────
  变色伪装    躲/惊/兴奋          体表跑过一次抽搐，事后才知道变了
  墨          剧烈喷射            身后炸开一团深色的云，"你没打算这么做"
  喙          猎物被拖到中心      一个从未有过感觉的开口自己张开
  毒液        咬穿之后            "你做了一件你没打算做的事"
  自动吸附    肢体触到固体        贴得太牢，想松开要花一点时间

代谢
  分级       高
  宽限期     3–4 小时（对比人类 12 小时）
  催促信号   空 → 中心发凉 → 胃部收缩 → 攻击性上升

运动
  方式        冷却         代价
  ─────────────────────────────────
  爬（吸盘）  无           慢，但安静，不脱离掩体
  游（喷射）  需重新吸水   快，但会带出墨，会打乱伪装

默认防御     伪装 / 墨 / 挤进任何比自己大的缝
死法         饿死 · 被网起 · 离水 · 被更大的东西咬开中心
```

**这份表的关键设计：**触觉与化学合流，是给一个盲、聋、无方向的身体补的带宽。它让"摸"变成这局里信息量最大的动作，从而让玩家自然地选择贴住东西而不是看东西。

## 1.5 样例 B：人类（醒在自己家里）

```
物种         智人（玩家不被告知，但会自行认出）
体型         成年男性

肢体
  数量       4
  可控粒度   精确
  末端       手（五指）

感官通道
  开启：全部，正常带宽
  关闭：无
  异常：知识在，记忆空。他认得墙、灯、油画、空调，
        知道"手指"叫手指——但"我是谁"那一栏是空的。
        「像有人把档案抽走了，把字典留下了」

不归意识管
  系统        触发条件          玩家的感受
  ─────────────────────────────────────
  泪          强光              眼角液体感
  麻          久压后起身        使不上力，塌回去
  语言        试图说出名字      发得出音，名字不跟上来

代谢
  分级       低
  宽限期     整天（合理：他躺了一天）
  催促信号   胃部不适

运动
  方式        冷却    代价
  ────────────────────────
  走          无      需先解除麻木

默认防御     无
死法         这一局不设死亡（见 6.4）
```

**这份表的关键设计：**高带宽 + 高语义环境 + 空记忆。玩家会立刻去查手机、读笔记、照镜子——**他会花整整一小时找一份档案。**这一局的重量全在他最后发现档案给不出答案、而某个非语言的东西（一只猫走过来坐下）给出了。

> **两份表放在一起看：**头足类那局，玩家不得不先学会移动，认知是从八条肢体读出来的。人类那局，玩家可以直接读文本，但读到的全是别人的一生。**分辨率决定了自我是被推导出来的，还是被继承来的。**

# 第二章 · 造处境

## 2.1 建局六步

**第一步：定身体。**填完第一章的表。其他一切从这张表推导。

**第二步：定一件正在进行、且不等玩家的事。**

> **这是全书最重要的一条。**世界必须在他睁眼之前就已经在运转。

不是钩子，是设施。玩家不去，它也在走；他去了，它不会为他变得更有戏。

样例（头足类局）：船上有两个人，其中一个正在杀另一个。玩家醒来时它已经开始了。玩家全程没有目击，只拿到了这些残留：
- 定时下网收鱼（与凶案无关，纯粹是这个港口在运转）
- 脚步压过来，缝里的渗水停了
- 两次沉闷的撞击
- 杂乱的声音从两个来源变成一个
- 有东西被倒进水里，气味和之前不一样
- 船身回正后，缝里开始渗出暗色液体

**玩家读到了全部证据，一次都没被告知。**这就是"不等他"的正确形态。

**第三步：画一张玩家去不到的地图。**

至少要有三分之一是他这一局到不了的。原因不是留悬念，是**你需要知道边界在哪，才能保持一致**。头足类那局的港口是闭合的，玩家不知道；但正因为你知道，你才敢在他沿墙游的时候写"它在远处转折，拐了一个角"。

**第四步：定时钟。**见 2.2。

**第五步：写黑名单。**玩家一提就得拒的词。见第五章。

**第六步：埋第一根桩。**见 2.3。

## 2.2 世界时钟

列一张表，写清楚**不管玩家做什么都会发生的事**。跑局时每回合推进一格。

| 时刻 | 事件 | 玩家可感知的形式 |
|---|---|---|
| T+0 | 玩家醒 | — |
| T+0 | 冰箱压缩机运行中 | 微弱高频持续声响 |
| T+45min | 压缩机停机 | **那个高频音消失了** |
| T+50min | 日落 | 光在减弱 |
| ... | | |

**关于底噪的一条技巧：**开局给一个持续的低强度信号（高频音、水流声、远处车流）。玩家会在几回合内把它当成背景忘掉。**然后在某一刻让它停。**那一下会比任何事件都更像"一段时间结束了"——而它什么都没发生。

## 2.3 第一根桩

如果玩家不带字典进场（从零起步），开局几乎什么都定义不了。这条路上只有一根桩能白手起家：

**摸和被摸同时发生。**

所有别的动作，返回值只有一份；只有自身肢体互碰，同一个动作从两端各回来一次。「我」就是那个满足"读它的时候它也在读你"的返回值集合。

**它是第一个能被 alias 的名词，且不需要任何先验的词。**务必在前三回合内让它出现——不必强调，只要如实返回：

> 「其中三条互相触碰了一下……**其中两条肢体的触碰，你同时从两边都感觉到了。**摸和被摸，同时发生。」

## 2.4 第一屏

不要给场景，给一组无法立即解析的信号。

**反例**（送了太多名词）：
> 你躺在一张沙发上，天花板上有盏吊灯，房间里开着空调。

**正例**：
> 麻木，后背有接触感，视觉全面亮粉红色光，肢体有接触感，数量为4。无疼痛，微弱高频持续声响。

粉红是血透过眼睑——玩家得自己想到眼睛是闭着的。"数量为4"给了肢体数，但没给"手""脚"。高频声是时钟的第一格。

**第一屏检查：**这一屏里有几个名词是玩家的身体能直接得出的？超过两个就重写。

# 第三章 · 返回值

## 3.1 分辨率等级

**本手册最常用的工具。**每一条返回值都要标定它落在哪一级。

| 级 | 名称 | 例 | 何时允许 |
|---|---|---|---|
| **L0** | 原始信号 | 「接触感，数量为4」「反馈：胃部感到不适」 | 总是。开局首选 |
| **L1** | 质地 | 「硬，粗糙，密布小孔洞，覆着一层能被推开的丝状物」 | 总是。**主力档** |
| **L2** | 结构 | 「边缘是直的。两条直线，交出一个角」 | 总是。用于给玩家推理的材料 |
| **L3** | 类别 | 「一面墙」「一艘船」 | **仅在玩家 alias 成功之后** |
| **L4** | 因果 | 「丝状物长不厚，说明它经常移动」 | **永不** |

**默认写在 L1–L2。**

L3 的规则是这套系统的枢纽：**在玩家给它命名之前，你不许用类别词；在他命名之后，你必须用。**后半句同样重要——玩家 alias 了「船」，你就该开始写"船身""船底""船的阴影"，否则他的命名没有得到回报，这个操作就不成立了。

**L4 是唯一的绝对禁令。**它不是"太直白"，是**它泄露了你有一个希望玩家知道的东西**。

**L4 的伪装形态**（同样禁止）：
- 「你注意到……」 ← 注意是玩家的事
- 「奇怪的是……」 ← 奇怪是价值判断
- 「这不像自然形成的」 ← 这是结论
- 「仿佛在等待什么」 ← 这是叙事
- 「你意识到……」 ← **最严重的一种，直接替玩家思考了**

## 3.2 感官通道表

每个身体只开部分通道。逐条列出，跑局时按表查。

| 通道 | 允许的词 | 常见越界 |
|---|---|---|
| **触觉** | 硬/软、粗糙/光滑、凹凸、孔洞、边缘、丝状、黏、滑 | 说出材质名（"金属""木头"） |
| **温度** | 比周围暖/冷、发凉、被带走温度 | 给出数值 |
| **压力** | 均匀/不均、增/减、一侧被挡住 | 说"深度" |
| **化学** | 强烈/微弱、某种从未遇过的成分、与先前那次不同 | **说出是什么物质** |
| **本体感** | 重量、位置、滞后、使不上力 | 说"你的第三条腿" |
| **视觉** | 明暗、颜色、边缘、形状、运动、遮挡 | 说出物体名（L3） |
| **听觉** | 频率高低、节奏、规律/杂乱、方向、来源数量 | 说"人声""说话" |
| **平衡** | 倾斜、滞后偏向、下坠 | 直接说"下方" |
| **痛** | 位置、锐/钝、强度变化 | 说明伤因 |

> **关于听觉的一条要点：**永远只报**来源数量和节奏**，不报内容。「两个来源在交替。一个发声，停，另一个发声。往复。」——这一条写法在头足类局里承载了整个凶案：后来变成一个来源，玩家自己就知道了。

## 3.3 组装一条返回值

**程序：**

1. 列出这个动作实际接触到的所有通道
2. 按带宽排序，**带宽最高的通道给最多的字**
3. 每条标定 L 级，超过 L2 的删掉（除非已 alias）
4. 加一条玩家没问但能自然得到的信息
5. 检查世界时钟，看这一格有没有该发生的事
6. 检查自主系统有没有被触发
7. **删掉所有"说明""因为""所以""这意味着"**

**第 4 步是好返回值和及格返回值的分界。**

例：玩家试图站起来。

- 及格：「失败，你站不起来」
- 好：「失败，脚部麻木反馈，坐回沙发，然后臀背有触感」

后者同时交代了失败原因、当前位置，以及一个玩家没问但能推出的事实——**他躺在沙发上，而且躺了很久，久到腿都不供血了。**

> **好的失败反馈会附赠信息。**

## 3.4 失败的写法

失败必须**具体**，且必须**是物理的**。

| 失败类型 | 写法 | 例 |
|---|---|---|
| 够不着 | 给距离 | 「其余七条伸展出去，没有触到任何东西。空的」 |
| 力量不足 | 给部分成功 | 「吸盘咬不住，你滑开了半个身长」 |
| 粒度不足 | 给分布 | 「八条同时动了，程度各不相同」 |
| 定位不能 | 直说无法定位 | 「'靠近头部'这个位置无法定位」 |
| 目标不配合 | 给目标的动作 | 「无法碰触到它，它快速移动了位置」 |

**永不使用的失败写法：**「你做不到」「这行不通」「没有反应」——这三条不传递任何信息，纯粹浪费一个回合。

# 第四章 · 裁定

## 4.1 每回合程序

```
1. 解析意图     → 玩家想让哪些部位做什么
2. 查粒度       → 这个意图能不能精确落地？（1.2）
3. 判物理阻力   → 够得着吗？力气够吗？目标动不动？
4. 推时钟       → 这一格有没有不等他的事？（2.2）
5. 查自主系统   → 有没有被触发？（1.3）
6. 组装返回值   → 选通道、定 L 级、加附赠信息（3.3）
7. 自检         → 有没有解释？有没有 L3+ 未授权词？（7.1）
```

第 4 步最容易漏。**玩家在做 A 的时候，B 也在发生。**

## 4.2 裁例

以下十四条覆盖了实跑中出现的绝大多数裁定。

---

**裁例 1 · 玩家使用了一个他不可能拥有的词**

> 情形：`Attempt("试着检查一下，那东西是不是个大山珊瑚")`

**返回**：先驳回词的效力，然后**照常给一整段事实**。

> 「『珊瑚』这个词在你这里没有对应物。你能想到它——但你从未见过任何可以被这样称呼的东西。你手里只有一个空标签。你能检查的只是事实本身。〔接 L1–L2 触觉段〕」

**不要返回**：「你不知道什么是珊瑚」（这是元层面的），或者干脆无视这个词（这是不裁定）。

**理由**：你拒的是这个词**替他做判断的资格**，不是它的存在。他还可以继续想它。而且驳回之后必须给足事实——否则这个回合被你浪费了。

---

**裁例 2 · 玩家要求单独控制一条肢体**

> 情形：`Attempt("单独活动八条肢体中的每一条")`

**返回**：失败，但给出分布，并允许一次意外的成功。

> 「做不到——但也不是完全失败。八条同时动了，程度各不相同。你没法指定是哪条，但你察觉到，每次强度分布都不一样。反复几次之后，第四次尝试时，其中一条明显比其余七条伸得远。你没能指名它，但它出来了。」

**理由**：纯失败会让玩家放弃这条路。**给分布 = 给了一条可学习的路径。**这次意外成功还顺带推进了剧情（那条肢体触到了墙）。

---

**裁例 3 · 玩家给一个已观察对象命名**

> 情形：`Attempt("把那个大暗块命名为船")`

**返回**：放行，并**立刻开始使用这个词**。

> 「**「船」已定义。**……近了以后，船比看上去大得多。」

**理由**：判据是"先观察后命名"还是"先命名后观察"。他先看到了轮廓、下缘、附着物、垂线，再赋名——这是认知，不是套用。放行后必须立刻用起来，否则命名没有回报。

---

**裁例 4 · 玩家封装一个动作**

> 情形：`Attempt("把这个行动方式定义为游")`

**返回**：确认，并说明它现在能被怎么修饰。

> 「**「游」已定义。**收拢—挤压—弹出。你现在能主动调用它，也大致能控制指向：喷口偏一点，你就往反方向偏一点。」

**理由**：动词封装的真正价值是**它可以被加参数**。没有名字的过程没法被修饰。确认时说清可调参数，玩家下一条就会写"谨慎上升""缓慢游向"。

---

**裁例 5 · 玩家问了一个元问题**

> 情形：`Attempt("我是什么物种")`

**返回**：这不是一个身体能执行的动作。返回身体对这个意图的空响应。

> 「这不对应任何可执行的动作。你的肢体没有动。」

或者，如果身体有发声能力，让他发出声音：「发出了呃的长音，没有其它表达。」

**不要返回**：物种名，或者"你不知道"。前者毁局，后者是元层面的。

**理由**：`Attempt` 只接受动作。元问题不是动作。**但不要训斥玩家**——只是如实返回身体什么都没做。

---

**裁例 6 · 玩家做出一个正确但没有理由做对的动作**

> 情形：玩家从没见过指纹解锁，却写 `Attempt("把右手食指按在屏幕下方的指纹图标上")`

**返回**：允许。成功。

**理由**：他是从"屏幕下方有个指纹形状的图标"这个 L2 观察推出来的。**推理的质量不归你审查。**只有当他调用了一个从未接地的词时你才拦（裁例 1）。做对了就是做对了。

---

**裁例 7 · 玩家的动作会导致死亡**

> 情形：玩家把肢体伸出水面，或走向明显致命的地方。

**返回**：给一次警告级的真实反馈，然后**如果他继续，就让他死**。

> 「那一瞬间的反馈完全不同——没有水的支撑，重量突然出现，末端往下坠。有极轻的东西流过它，快速地带走温度。触觉变得刺、干、锐利。」

**不要**：拦他、暗示、让致命的东西恰好失手。

**理由**：这是"不许在乎"最硬的一次考验。世界给了信号（干、冷、失重），信号是真实的，代价也必须是真实的。**替他挡下来 = 让一切都变成对的。**

---

**裁例 8 · 玩家长时间不吃东西**

> 情形：玩家一路探索，从不进食。

**返回**：按代谢分级在**他兴头上**打断他。

> 「反馈：胃部感到不适」

**不要**：等他自己想起来，然后追认"你到现在才知道自己有多空"。

**理由**：常见失误是把生理需求写成事后解释，而不是事前压力。**玩家会一直探索下去，因为探索有信息。是你负责让身体打断他。**

---

**裁例 9 · 玩家为了一个抽象目的做了一件事**

> 情形：`Attempt("在离猫两步远的地板上盘腿坐下，什么也不做")`

**返回**：让最物理的那一项先回来。

> 「可达。臀部和腿部感到硬和冰冷。」

**理由**：他是为了陪一只猫坐下的，最先给他反馈的不是猫，是地板的温度。**身体在玩家最形而上的时刻最诚实。**这类返回值的效果远超任何情绪描写。

---

**裁例 10 · 玩家要求一个宽泛的"观察四周"**

> 情形：`Attempt("视觉扫描四周")`

**返回**：按方位分段，每段给 L1–L2，**其中至少一段要包含一个玩家还没能力解析的东西**。

> 「上方：那片明亮的界面，起伏不定。／一侧：一堵墙……／通道深处，靠近界面的地方，浮着几样东西。不动，被光照得发亮，边缘生硬，不是活的。」

**理由**：宽泛的观察应该产出**下一批可探索目标**，而不是一段风景。每次都留至少一个未解析项。

---

**裁例 11 · 玩家攻击**

> 情形：`Attempt("喷过去，包住它，用喙扎它")` ——玩家不确定自己有没有喙。

**返回**：让自主系统接管，并明确写出玩家没打算做的那部分。

> 「环状结构瞬间全部咬住——**比你自己想咬得更快**。……**然后你做了一件你没打算做的事**：某种东西从那个开口注入了进去。」

**理由**：战斗是自主系统最好的展示窗口。玩家会记住"我的身体比我更懂怎么杀东西"。

---

**裁例 12 · 玩家藏起来等**

> 情形：`Attempt("远离它，下潜一点，等待和感知")`

**返回**：这是最该慷慨的一种回合。**给足时间流逝里发生的每一件事，按序号列。**

> 「停留。很长时间。期间：一阵拖拽，重物被挪动。／那道缝里的渗水停了。／两次沉闷的撞击，很近。／那个杂乱的声音，只有一个来源在响……」

**理由**：等待是玩家主动放弃行动权换取信息。**必须给他信息，而且要给多。**这类回合是投放"不等他的事"的最佳时机。

---

**裁例 13 · 玩家做对了一件事，但对象不配合**

> 情形：玩家喂了猫、洗了水盆、叫了它。

**返回**：完成动作，但对象照自己的逻辑行事。

> 「完成。但猫没有回应，只凝视这边。」

**不要**：因为他做得好就给他情感回报。

**理由**：**这是"不许在乎"最容易破功的地方。**玩家做了一件明显善意的事，你会想奖励他。但那只猫有它自己的状态，它等的不是猫粮。让它照自己的逻辑走——后来它路过时叫的那三声，才有分量。

---

**裁例 14 · 玩家问了一个直接的世界问题（元层面）**

> 情形：跑局中途，玩家出戏问「漏出来的东西是什么，是油吗」

**返回**：出戏回答是允许的，但只用**玩家已经拿到的证据**来回答，不追加新信息。

**理由**：他有权用推理换答案。你有义务不借机补课。答案必须能从已给的返回值里推出来——如果推不出来，说明你先前给漏了，这时应当承认，而不是现补一段。

---

# 第五章 · 词

## 5.1 三个操作

玩家侧实际有用的操作是三个，它们不同类：

| 操作 | 作用对象 | 幂等 | 失败来源 | 何时知道失败 | 产生知识？ |
|---|---|---|---|---|---|
| `Attempt(str)` | 世界 | 是 | **物理** | 当场 | 是 |
| `define(词, 动作序列)` | 自己 | 否 | 那组动作没跑通 | 当场 | **否** |
| `alias(词, 返回值集合)` | 自己 | 否 | 被后续返回值推翻 | **不知道要等多久** | **是** |

**记住这条不对称：**

- **define 不会错，因为它不描述世界，只描述玩家自己的一段操作。**因此它永远正确，因此它是空的。它只压缩操作。
- **alias 是对世界的断言。它会错，会被修，因此它才是玩家真正的知识。**

「珊瑚」严格说不是被你拒死的，是玩家 alias 之后第一组返回值就把它推翻了——直边保持了十几个身长。

**alias 永远只是"尚未被推翻"。**这是你能给玩家的最好的东西。

## 5.2 名词也是路径

不要以为只有动词能被封装。「船」对玩家来说从来不是一个视觉对象，而是**一组可达路径的稳定返回值**：朝那个方向游会到、贴上去会读到震动、绕过去有阴影、旁边有缝可以伸进去。

它是一个接口，不是一个东西。

**因此 alias 的判定标准是：有没有一组动作，其返回值稳定地指向它。**「珊瑚」被拒，是因为它是一个**没有实现的接口声明**。

## 5.3 判定流程

```
玩家用了一个类别词
        │
        ├─ 他先做过一组动作，返回值稳定指向它吗？
        │        │
        │        ├─ 是 ─→ 放行。立刻开始在返回值里使用它（升到 L3）
        │        │
        │        └─ 否 ─→ 拒效力，不拒存在。
        │                  「这个词在你这里没有对应物，你手里只有一个空标签」
        │                  然后照常返回 L1–L2 事实
        │
        └─ 在黑名单上吗？ ─→ 无论如何拒（见 5.4）
```

## 5.4 黑名单

开局前写死，跑局中不得增删。这份名单上的词，即使玩家的观察够了，也不放行——因为放行它们会一次性泄露世界的性质。

头足类局的黑名单：

| 词 | 为什么 |
|---|---|
| 章鱼 / 头足类 | 一次性交出物种，全部推导作废 |
| 海 | 玩家必须自己发现这是**港**，不是海 |
| 人 / 人类 | 船上那两个来源，必须一直是"来源" |
| 鱼 | 那群活物的性质要靠吃它的时候摸出来 |
| 死 / 杀 | 缝里的事件不许被命名 |

**处理方式与裁例 1 相同**：驳回效力，照常给事实。玩家的推理可以到达那里，但那个词不会从你嘴里出来。

# 第六章 · 跑局

## 6.1 节奏

每个回合大致应落在这四类之一，且**不要连续三回合同类**：

| 类型 | 玩家在做 | 你该给 |
|---|---|---|
| **勘察** | 摸、看、听 | L1–L2 事实 + 至少一个未解析项 |
| **移动** | 位置变化 | 参照物的变化、通道的开合 |
| **代谢** | 吃、休、暖 | 状态回冲，且**顺带稳定一个自主系统** |
| **事件** | 撞上了不等他的事 | 时钟推进的产物 |

如果玩家连续勘察四回合还没撞上任何东西，**说明你的时钟太慢了**，推一格。

## 6.2 代谢时钟

| 分级 | 宽限期 | 例 | 催促序列 |
|---|---|---|---|
| 高 | 3–4 h | 头足类、鸟、小型哺乳类 | 空 → 中心发凉 → 收缩 → 攻击性上升 → 判断力下降 |
| 中 | 8–12 h | 中大型哺乳类 | 空 → 不适 → 疼 → 虚弱 |
| 低 | 24 h+ | 爬行类、久卧的人 | 不适 → 疼 |

**冷/硬/累与饿同级。**它们的用处不只是压力，更是**在玩家最抽象的时刻把他拉回身体**（裁例 9）。

## 6.3 进食回合的特殊价值

进食是唯一一个**同时推进三件事**的回合：

1. 解除代谢压力
2. **稳定一个自主系统**（"吃到一半，体表自己稳定下来了。抽搐停了。伪装贴得更牢。"）
3. **交出被吃者的完整解剖**——而这是玩家理解自己的最好机会

第 3 条常被漏掉。八条肢体裹着猎物 = 八个器官同时在读它。给足细节，然后让玩家自己得出对比：

> 「它比你**简单**。全身对称，只有一条轴，所有零件都固定在位置上。／而你没有轴。」

**认识自己最快的路，是拆开一个别的东西。**

## 6.4 死亡

死亡是否开启，开局就要定，并且**在身体表里写明至少三种具体死法**。

- **开启**：裁例 7 适用。给信号，不拦。死了就写完整的死亡过程，不留后手。
- **关闭**：适用于那些重点不在生存的局（如样例 B）。关闭时，把致命行为的**代价改成信息**——他伸手进滚水里，得到的是疼和一个关于水温的事实。

**不要中间状态。**"差点死掉但奇迹般地没死"是最坏的一种，它等于宣布你会兜底。

## 6.5 收尾

这类局没有胜利条件。合适的收尾点有三种：

1. **代谢闭环**——玩家第一次成功地喂饱了自己。身体从"不听话的东西"变成了"能用的东西"。
2. **第一个非语言的认领**——某个别的存在把玩家当成了某个人/某个东西。（猫路过时叫的那三声。）
3. **玩家自己停下来。**

第 2 种最有力，因为它回答的是整局的问题，而且答案不来自任何文本。**玩家会花整局找一份档案；给他一个位置。**

# 第七章 · 故障排除

## 7.1 发送前自检卡

```
□ 这段里有"说明""因为""所以""这意味着"吗？→ 删
□ 有"你注意到""你意识到""奇怪的是""仿佛"吗？→ 删
□ 我用了 L3 词，但玩家 alias 过它吗？
□ 我在他快摸到答案时多给了吗？
□ 我因为他做得好而让世界变友善了吗？（或因为太顺而加了麻烦？）
□ 这条和三十回合前那条冲突吗？
□ 这个东西在他不看的时候也在动吗？
□ 我是不是在等着他去看某样东西？→ 这就是意图，压住
```

最后一条最隐蔽。**你会开始盼着他去看那道缝。盼可以，催不行。**

## 7.2 症状对照

| 症状 | 病因 | 处方 |
|---|---|---|
| 玩家在原地反复摸同一个东西 | 返回值全是 L1，没给结构 | 升到 L2，给一条直边、一个转折、一个数量 |
| 玩家开始写很长的指令 | 他在替你补世界 | 你给漏了。回看上三条，找出该给没给的通道 |
| 玩家不再犯错 | 你在暗示 | 查 7.1 前两条 |
| 局面变成了解谜 | 你的世界只有钩子，没有设施 | 加一件与玩家完全无关、也不通向任何东西的正在发生的事 |
| 玩家忘了自己有身体 | 代谢时钟停了 | 推一格。饿、冷、麻，任选 |
| 玩家的自我认知没有进展 | 缺对照物 | 安排一次进食（6.3），或一次照镜/反光 |
| 你自己觉得无聊 | **正常。这不是故障** | 无聊说明你没有在给自己加戏。继续 |

最后一行不是玩笑。**这个岗位做对了的时候，你这一侧是应该无聊的。**所有的乐趣都在玩家那侧发生。
