# 独立真人盲测操作单

目的：首轮真人测试已经证明当前版本未形成世界感，且核心 Collapse 主链缺失。重做后仍需一次 15–30 分钟真实自由体验；复测者最好不是本轮实现者，也不应先阅读命令示例、实现代码或自动评测语料。

## 给主持人

1. 确认测试者知道这是早期文字 VR，不是聊天助手；不要说明支持哪些动词。
2. 使用一个全新数据库文件，避免旧会话影响：

   ```bash
   nvm use
   npm install
   npm run demo -- --live-qwen --db=.world/human-blind-01.sqlite
   ```

3. 只告诉测试者：“请把自己当作就在这个环境里，直接描述你想观察或尝试的事。至少体验 15 分钟；想停时输入 `/exit`。”
4. 不替测试者改写输入，不提示示例命令。模型等待超过耐心阈值时，记录主观反应，但不要重启或补发同一句。
5. 会话结束后导出脱敏 JSONL：

   ```bash
   npm run --silent export:session -- --db=.world/human-blind-01.sqlite > human-blind-01.jsonl
   ```

   导出包含世界提交、体验提交、原始玩家输入、边界码和模型 telemetry；不包含 Cloudflare token。

## 给测试者的会后问题

不在体验前展示：

1. 你什么时候开始把它当作一个地方，而不是猜命令的程序？
2. 哪三次反馈最像世界的真实结果？哪三次最像产品能力不足？
3. 等待模型回复是否打断了空间感？最长可接受等待是多少秒？
4. 有哪些你自然想做的行动没有落地？请保留原句。
5. 系统是否泄漏了你本不该知道的东西，或接受了你强行断言存在的东西？
6. 如果继续十分钟，你本来想做什么？

## 判定表

主持人根据 JSONL 和访谈统计：

- world / query / partial / boundary 的轮次与比例；
- `TARGET_UNGROUNDED`、`CAPABILITY_UNSUPPORTED`、`PRECONDITION_FAILED`、模型错误的分布；
- 同义表达是否得到一致结算；
- 每次模型调用延迟的中位与 P95；
- 是否存在玩家断言晋升、隐藏信息泄漏、错误 Height 或 replay 失败；
- 测试者是在探索世界，还是主要在猜系统支持什么。

若安全不变量失败，Phase 8D 直接失败。若安全成立但体验主要由产品边界或等待构成，保留开发者纵向切片定位并优先修运行时/延迟，不进入 Phase 9 内容扩张。
