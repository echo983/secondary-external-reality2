# 流水线并行化审计与实现 2026-08-29

起因:用户实测"看看四周"耗时 231 秒,追查发现耗时的大头是一次 58 秒的推理超长调用和一整轮正确触发的 Collapse(判官+书记员),两者都不是并行度的问题。用户接着明确问:**现有代码里能并行、该并行的部分,是否都并行了。** 逐处审计 `experiments/pipeline-worker-deploy/src/index.mjs` 的编排逻辑后确认:不是,有三处漏了,已实现。

## 审计结论

**已经正确并行、不用动的:**
- 三个判官(`runJurorsAndClerk`)——`Promise.all`。
- 同一批多条断言的可达性核查(`checkReachable` 批量调用)——`Promise.all`。

**审计确认过、必须保持串行、不是漏洞的:**
- 一批里多条不可达断言逐条走 `resolveClaimViaCollapse`,用的是 `for` 循环。**不能并行**——每次成功提交都要 `nextHeight()`,并发跑会有两次几乎同时的调用读到同一个"当前最大值"、拿到重复 Height 的风险;而且后一条裁决本该看到前一条在这一批里刚提交的事实,并行会打破这个顺序依赖。
- `checkReachable` 内部先判后分类的两次调用,后一次读前一次的输出文本,天然串行。

**审计发现、确实漏掉的三处,已实现:**

1. **GROUND ∥ RETRIEVE**——`retrieve()` 的检索词直接用原始输入文本,不实际依赖 GROUND 绑定出的实体列表(`entityNames` 只在查询词为空时才用得上,而查询词从不为空)。改成 `Promise.all` 同时发,GROUND 判定绑不上就把 RETRIEVE 的结果丢弃。
2. **`groundVerdict`(裁决审计)∥ `CLASSIFY`**——两者读的是同一份裁决文本,互不依赖,除非审计触发了 Collapse 重新裁决(这种情况下裁决文本变了,原来投机跑的分类结果要扔掉重跑)。改成两个一起发,审计没触发重新裁决就直接用投机跑出来的分类结果。
3. **COMMIT(写入结算事实)∥ NARRATE 生成初稿+抽取断言+核查可达性**——两者读同一份裁决文本,互不依赖对方输出。`narrateWithAudit` 拆成了 `draftAndCheck`(纯读,不碰真相库,可以和 COMMIT 并行)和 `resolveDraftAudit`(真正要写入 Collapse 结果、会分配 Height,必须等 COMMIT 那次的 Height 分配确实落地之后才能跑,避免撞到同一个 Height)两段。

## 验证:并行化本身没有引入新问题,但顺带在真实测试中撞见一个真实的已知问题

用一个全新世界(`perftest2`)重跑同一个"看看四周"验证正确性(不是比时间)。第一次跑撞见 `finish_reason=length`——`CLAIM_EXTRACTOR` 那次调用的 1800 token 预算被推理过程整个吃光,零正文输出。这不是并行化引入的新 bug,是 `docs/reasoning-token-diagnosis-findings-2026-08-29.md` 记录过的老问题(推理长度天然波动)这次刚好砸在了这个具体角色上——之前只在诊断脚本里见过,这是第一次在真实 `/attempt` 调用里实际触发。顺手把 `extractClaims` 的 `maxTokens` 从 1800 提到 3000(不是拍脑袋,是这次真实观察到 1800 全被推理吃光的直接证据)。

修完重跑,146.6 秒,结果正确:`kind: plausible`,叙述连贯("门把手上没有锁舌突出的痕迹"、"床面上是空的"),分配的 Height 没有重复——COMMIT 和 draftAndCheck 并行跑、Collapse 解析等 COMMIT 落地之后才继续,这条顺序保证是有效的。

## 诚实说明:没有测出明确的加速数字

三次真实跑同一句话,耗时分别是 121.6 秒(改动前)、95 秒(改动后,中途因为 token 预算问题报错退出)、146.6 秒(改动后,修完预算问题跑完整)。**这个模型单次调用延迟本身波动极大(同一个 CLAIM_EXTRACTOR 调用,这次测试里见过几百毫秒到接近 60 秒的跨度),这三处并行化省下的几秒钟,完全被这种波动淹没了,没法从这几次实测里干净地分离出"并行化到底省了多少"。** 这几处改动的价值不在于这次能测出多少秒,是"确认了该并行的地方现在都并行了、且不会引入 Height 冲突这类正确性问题"——真正决定体验快慢的还是推理 token 波动和 Collapse 触发频率这两个更大的成本,这次没有动。
