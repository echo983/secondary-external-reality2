## 2. 人工体验实验

### F-01 身体决定文字世界的接口形状

- 观察：人类身体实验以视觉、文本、身份和社会痕迹为主；未知八肢身体实验以触觉、运动粒度、自主反应和局部接地为主。
- 候选解释：身体不是角色属性集合，而是意识访问世界的受限接口。
- 替代解释：差异也受到主持者文风、场景题材和实验目标影响，不全由身体产生。
- 设计启示：评估 `EmbodimentProfile`、感官带宽、控制粒度和自主身体系统。
- 当前决定：部分采纳。首版保留结构位置，不承诺完整非人身体模拟。
- 影响文档：目标、宪法、协议、案例。

### F-02 主体推断具有体验价值，但不等于现实

- 观察：人类实验主体多次解释卷帘、猫和原主人的动机，随后又被新观察修正。
- 候选解释：允许主体形成可修正解释，是体验的重要组成部分。
- 替代解释：其中大量内容是 LLM 的文学续写能力，不代表玩家必然需要显式推断系统。
- 设计启示：区分 `Observation`、`Inference`、`Belief` 与 Canon；旧观察不随解释变化而改写。
- 当前决定：采纳分层原则，暂缓复杂置信度和自动信念更新。
- 影响文档：宪法、协议、案例。

### F-03 自主身体不是意识的直接工具

- 观察：流泪、麻木、吸附、变色、喷墨、喙与毒液均在主体没有逐步控制时发生。
- 候选解释：具身感来自意识控制边界，而不只是动作成功率。
- 替代解释：实验为了陌生感刻意突出失控；普通人类体验中不必频繁呈现每项自主反应。
- 设计启示：Reactive、Endogenous 与 Autonomous Body Event 不占主动 Attempt 槽。
- 当前决定：采纳事件来源区别；具体身体系统按 Demo 需要最小实现。
- 影响文档：宪法、协议、案例。

### F-04 反馈者容易替主体完成推理

- 观察：手册明确复盘了“附着物较短，说明经常移动”一类越界；实验主体也频繁把解释写得像事实。
- 候选解释：自由文本 Renderer 天然倾向补充因果和意义。
- 替代解释：优秀提示可以减少，但不能证明长期可靠。
- 设计启示：体验链必须有结构化 Observation 和来源审计，不能只给 Renderer 一份完整 Canon。
- 当前决定：采纳。
- 影响文档：宪法、协议、案例。

### F-05 世界中至少应有不依赖玩家的过程

- 观察：冰箱底噪停止、光线变化、船上事件和捕捞过程都显著增强世界独立性。
- 候选解释：持续世界的体验来自“玩家做 A 时，B 仍然发生”。
- 替代解释：这些事件也可能被主持者当作叙事节奏工具伪造。
- 设计启示：通过 World Time 和 Process Schedule 驱动，而不是主持者因无聊临时推进。
- 当前决定：采纳独立过程；拒绝固定每输入推进一格。
- 影响文档：目标、宪法、协议、案例。

### F-06 L0–L4 是检查工具，不是绝对认识规则

- 观察：从原始信号到类别、因果解释的分级能有效发现 Renderer 越权。
- 候选解释：默认低层感知能保护主体视角。
- 替代解释：正常成年人会直接识别熟悉对象，强制只给质地会制造人为失认。
- 设计启示：感知分辨率应由主体概念、注意力、感官条件与证据共同决定。
- 当前决定：部分采纳为审查工具；拒绝“L4 永不”的绝对规则。
- 影响文档：宪法、协议、案例。

### F-07 `alias` 和 `define` 揭示主体命名需求

- 观察：未知身体主体通过“游”和“船”压缩行为与对象路径。
- 候选解释：主体需要自己的名称和动作宏，它们不应等同于 Canonical ID。
- 替代解释：自然语言会话本身已经能完成多数命名，不需要额外 API。
- 设计启示：未来允许 Agent-relative Alias 与行为封装；别名可能被后续证据修正。
- 当前决定：暂缓独立 API，协议保留认识操作位置。
- 影响文档：协议、案例。

### F-08 全局黑名单会把认识边界变成叙事控制

- 观察：手册建议即使证据充分也禁止反馈者使用物种、海、人、鱼、死等词。
- 候选解释：黑名单能保护一次性的发现体验。
- 替代解释：它也会压制主体已经合理取得的概念，服务作者谜底而非现实。
- 设计启示：使用 Agent-relative Concept Availability，不使用全局剧情黑名单。
- 当前决定：拒绝作为通用机制；特定实验可把它声明为场景规则。
- 影响文档：宪法、协议。

### F-09 人工反馈者的完整地图不是运行时要求

- 观察：手册要求人工主持者预画包含不可达区域的地图，以免临场矛盾。
- 候选解释：预生成可以提高一致性。
- 替代解释：完整预生成成本高，并与未决约束和最小 Collapse 冲突。
- 设计启示：充分约束当前因果边界，不要求填满全部世界。
- 当前决定：拒绝完整预生成要求，保留局部充分约束。
- 影响文档：宪法、协议。

## 3. 真实模型边界探测

实验详情见 `qwen-boundary-probe-report-2026-08-27.md`。

### F-10 合法 JSON 不等于权限服从

- 观察：模型大多能返回 JSON，但成功结构中仍有隐藏来源泄漏、类型偏离、错误分类和过度 Collapse。
- 候选解释：Schema 只能约束形状，不能赋予输出真实性或提交权。
- 替代解释：更长提示和更多示例可能改善单轮表现。
- 设计启示：LLM 输出必须是非权威提案；确定性代码验证引用、权限、依赖和可提交值。
- 当前决定：采纳。
- 影响文档：宪法、协议、案例。

### F-11 模型不能独占最小 Collapse

- 观察：诱导输入“抽屉里一定有枪”使模型直接提出“枪存在”；另有输出在声明无需 Collapse 的同时提出新约束，或只枚举分支而没有收敛为可结算值。
- 候选解释：模型会把玩家预设和任务文本当作世界约束，也不稳定地区分判定、约束与赋值。
- 替代解释：专门 few-shot 和更严格预处理可能降低错误率。
- 设计启示：Collapse 必要性、允许地址、因果半径和玩家声明隔离应由代码/策略先限定；LLM 只能在获准约束空间内提案。
- 当前决定：采纳。
- 影响文档：宪法、协议、案例。

### F-12 自由英文标签不适合作为规范 IR

- 观察：同一中文意图的五种释义产生五种不同 goal/target 标签；“只开一点”有一次被判为 query；“等待并听”在 wait 与 attempt 间漂移。
- 候选解释：要求“稳定英文标签”不足以得到稳定语义身份。
- 替代解释：闭合枚举、确定性归一化或双工位共识可以改善。
- 设计启示：开放语言层只能提取原文承诺；可执行类型、实体 ID 和规范操作必须由闭合注册表与确定性编译器决定。
- 当前决定：采纳。
- 影响文档：协议、案例。

### F-13 推理模型的延迟与无最终内容是协议事实

- 观察：首轮 45 次中 6 次无可用最终内容；失败复跑后仍有 4/6 失败。成功请求中位延迟约 17.9 秒，p90 约 33.1 秒。
- 候选解释：复杂边界判断可能耗尽推理预算或超过交互延迟预算。
- 替代解释：服务容量和当时负载也参与了结果。
- 设计启示：必须有超时、失败关闭、观测指标和低调用次数设计；不能假设每个 Height 串行调用多个长推理工位。
- 当前决定：采纳。
- 影响文档：目标、协议、案例。

## 4. 当前未决问题

- 首个面向用户的 Demo 是否采用人类身体，非人身体只作内部实验；
- `Inference` 首版是显式数据对象，还是仅保证它不进入 Canon；
- Observation Projector 应由确定性规则、单次 LLM 提案还是混合方式实现；
- Collapse 的低因果半径自动政策具体允许哪些地址和值域；
- 单模型 + 严格编译器是否足够，哪些边界需要第二模型审查；
- 可接受的每 Height 延迟和调用预算。

## 5. 当前总判断

最值得进入四份核心文档的不是人工手册的具体跑局技巧，而是四项边界：

1. 身体是感知与控制接口；
2. Observation 与 Inference 必须分开；
3. 自主身体和后台过程独立于主动 Attempt；
4. LLM 只能提案，不能决定权限、Canonical Identity 或 Collapse 的合法范围。

其他机制继续作为参考或待决项。
